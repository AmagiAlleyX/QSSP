# 秋牲起始页 (QSSP)

一款高颜值、高度可定制的浏览器起始页 / 新标签页。集动态壁纸、Live2D 看板娘、粒子特效、音乐播放、专注计时、天气、快速导航于一体，让你的浏览器首页变得既好看又好用。

## 功能概览

| 模块 | 功能说明 |
|------|---------|
| **动态壁纸** | 支持 Bing 每日一图、Picsum、Unsplash、本地自定义上传等多种来源 |
| **粒子效果** | 樱花飘落、雪花纷飞、雨滴下落三种动态粒子，支持开关 |
| **Live2D 看板娘** | 内置多款 Live2D 模型，支持换装、拍照、互动对话 |
| **数字时钟** | 实时显示时间，支持农历日期与节日问候 |
| **音乐播放器** | 支持本地 MP3 导入，自动提取 ID3 封面与歌词 |
| **快速导航** | 可自定义网站快捷方式，支持拖拽排序、分页管理 |
| **搜索框** | 支持 Bing、Google、百度等多引擎切换 |
| **天气** | 实时天气信息与未来预报 |
| **专注计时** | 番茄钟模式，支持专注/休息循环 |
| **主题系统** | 12+ 预设主题 + 自定义配色，支持明/暗/水晶模式 |
| **背景调节** | 遮罩透明度、高斯模糊强度自由调节 |
| **数据同步** | 配置导出/导入，支持本地备份与迁移 |
| **极简模式** | 一键隐藏所有装饰，回归纯粹 |

## 技术栈

- **Vue 3** — 渐进式前端框架
- **Vite** — 下一代前端构建工具
- **Canvas 2D** — 粒子特效渲染
- **Live2D Cubism** — 看板娘动画引擎
- **IndexedDB** — 壁纸等大型数据本地存储
- **localStorage** — 用户配置持久化

## 性能优化

本项目针对性能做了大量优化，确保在各种设备上流畅运行：

- **首屏加载优化** — 音频资源懒加载，避免阻塞首屏渲染
- **DPR 自适应** — 手机端强制 DPR=1，桌面端限制最大 DPR=2
- **粒子分级渲染** — 手机端固定低粒子数，桌面端按硬件性能动态调整
- **FPS 自适应降级** — 帧率低于 25fps 时自动减少粒子数量
- **离屏渲染优化** — 标签页隐藏时自动暂停动画，节省 CPU/GPU
- **CSS 性能优化** — `transition` 收窄为具体属性，减少 layout/paint
- **拖拽优化** — 使用 `transform: translate` 替代 `left/top`，避免 reflow
- **构建优化** — 开启 gzip + brotli 预压缩，代码分割按需加载
- **内存泄漏修复** — 事件监听器正确移除，Blob URL 及时释放

## 使用说明

### 首次使用

1. 打开页面后，点击右上角 **设置** 图标进入设置面板
2. 在 **背景设置** 中选择喜欢的壁纸来源或上传本地图片
3. 在 **主题设置** 中切换配色方案
4. 在 **快速网站** 中添加常用网站快捷方式

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 搜索框聚焦时执行搜索 |
| `Esc` | 关闭当前弹窗/面板 |

### 数据备份

所有配置自动保存在浏览器本地存储中。如需迁移或备份，可在设置面板中导出 JSON 配置文件，在新设备上导入即可恢复全部设置。
